# Registro de Gastos

Proyecto de consola desarrollado en C# (.NET) para la gestión y control de gastos personales, implementando programación orientada a objetos, colecciones (`List<T>`), menús interactivos, manejo de excepciones/validaciones con `TryParse`, paso de parámetros por referencia (`ref`), y persistencia de datos en archivos CSV.

## Requisitos Previos
- **Visual Studio Community 2026** (o versión compatible con .NET Core/.NET).

## Pasos para Ejecutar el Proyecto

1. Clona el repositorio o descarga el código fuente en tu computadora.
2. Abre el archivo de solución (`.sln`) o la carpeta del proyecto en **Visual Studio Community 2026**.
3. Presiona **`F5`** o **`Ctrl + F5`** en tu teclado para compilar y ejecutar la aplicación de consola.
4. Interactúa con el menú eligiendo las opciones del 1 al 4 según corresponda.
